# Plan status

Audited against the native Rust tree on 2026-10-09. A Python-era plan's
"shipped" label describes that historical release; it is not evidence that
every proposed extension exists in Rust.

| Work | Current status |
| --- | --- |
| [Session Docker isolation](session-isolation-docker.md) | Native, open-egress and offline Linux profiles have private clones, TUI controls and effective cgroup checks. The gateway validates TLS SNI, and descriptor-bound XFS inspection covers session directories. Beta.28 adds an opt-in aggregate `EDQUOT` and container-restart fixture across three binds. Production hardened admission still needs live broker-path, quota, Engine restart/remount and provider egress proof. See the [operator guide](../session-isolation.md). |
| [Independent fleet supervision](fleet-supervision.md) | Typed host gates, selectable independent review, frozen scopes, handoffs and explicit dependency release exist. Beta.24 adds opt-in automatic receipts from owner-reviewed frozen offline Docker recipes after host-observed worker turns, with bounded attempts and cancellation on stop; dependency release remains human-owned. Live rootless cleanup, full fleet validation and a consented real-message corpus remain open. See the [operator guide](../fleet-supervision.md). |
| [Remote hub and Android](remote-hub.md) | Native/browser control, an encrypted Chrome client, browser Web Push and opt-in mixed-pane restore exist. Android FCM source tests and offline emulator builds pass. Beta.28 saves body-free markers before writes, fences uncertain outcomes, and binds approvals to exact reviewed inputs and random session incarnations. Provisioned device/FCM and two-host tailnet QA remain open. |
| [Model registry](model-registry.md) | Exact-model sourced facts feed the picker and conservative budget bounds. Beta.23 adds read-only `doxa model-facts` with per-field source dates and operator-selected review candidates. The `gpt-6-astra` supervisor and judge selectors have sourced facts and regression coverage; live account availability, latency, billed tier and provider charge remain unknown. Provider catalogs still control availability. |
| [Code graph](code-graph.md) | Bounded Rust and Python syntax queries and reviewed LORE 0.62.20 snapshots are available. Complete Git-listed scans of either language carry separate read-time freshness checks; Python module layout matches remain candidates, not runtime bindings. The [full-scan benchmark](../codegraph-scan-benchmark-2026-10-09.md) is read-only. A [restricted rust-analyzer contract](codegraph-semantic-verification.md), bounded LSP driver, and disabled Docker observation seam exist. The CLI reports unknown; live containment proof, verified semantic binding, and an automatic index remain open. |
| [DOXA plugin API](plugin-api.md) | Owner-allowlisted text commands and status files are data only. An explicit, owner-approved, zero-grant Linux CLI prototype requires an empty delegated cgroup parent and separate supervisor leaf. An ignored [delegated-host acceptance fixture](../native-plugins.md#delegated-host-acceptance-fixture) has not run on a delegated host. TUI activation, grants, hooks, and provider extensions remain open. |
| [Mermaid transcript diagrams](mermaid.md) | Opt-in local previews, sandbox doctor and beta.16 Settings preflight exist. A private session PNG cache binds source, width, and renderer package identity. A pinned real CLI suite passed fixed diagrams in Linux sandbox; real terminal graphics QA and an optional installer decision remain open. |
| [Collection triage](collection-triage.md) | Suggested names, settled opt-in group sorting and verified local LORE pending rank exist. Beta.16 added verified project heading hues and hidden-tab urgency; beta.17 added pane-row navigation, manual collection hues and label rename. Beta.18 adds `/collection project-label` for freshly verified canonical roots; unresolved or mixed roots stay read-only. |
| [macOS daemon process coverage](https://github.com/docwilde/doxa/issues/197) | Portable crates and daemon process tests run in macOS CI; beta.15 verifies production peer delivery and fleet PID admission. An opt-in source-only Claude lifecycle harness is available; an authenticated macOS pass and protected Codex success remain unverified. |

Native UI, LORE, provider and remote parity is tracked in
