# Plan status

Audited against the native Rust tree on 2026-10-09. A Python-era plan's
"shipped" label describes that historical release; it is not evidence that
every proposed extension exists in Rust.

| Work | Current status |
| --- | --- |
| [Session Docker isolation](session-isolation-docker.md) | Native, open-egress and offline Linux profiles ship with private clones and cgroup checks. The gateway checks exact SNI/DNS and bounds the ClientHello. Ext4 four-bind `EDQUOT` and a 32-case helper/client/install fixture passed in disposable guests. Inactive root-owned systemd templates and a read-only install preflight require an independently reviewed helper digest; no installed-host activation has run. Production hook frames require per-message kernel writer metadata, and a guarded gateway pins connector scope before DNS; a four-case guest proves its kernel-scope checks. Exact Engine, writer-to-container and provider origin remain unproved, so hardened production admission stays closed. See the [operator guide](../session-isolation.md). |
| [Independent fleet supervision](fleet-supervision.md) | Typed host gates, selectable independent review and frozen scopes exist. Dependency release binds a work checkpoint, its successor handoff turn, receiver read-back, sender agreement, and the latest handoff to explicit human review. Opt-in automatic test receipts remain separate from release. A read-only debrief reports bounded host evidence after a run. Live full-fleet validation and a consented real-message corpus remain open. See the [operator guide](../fleet-supervision.md). |
| [Remote hub and Android](remote-hub.md) | Native/browser control, an encrypted Chrome client, browser Web Push and opt-in mixed-pane restore exist. Android FCM source tests and offline emulator builds pass; the normal connection and synthetic recovery screens were captured offline. Beta.28 saves body-free markers before writes, fences uncertain outcomes, and binds approvals to exact reviewed inputs and random session incarnations. Provisioned device/FCM and two-host tailnet QA remain open. |
| [Model registry](model-registry.md) | Exact-model sourced facts feed the picker and conservative budget bounds. Beta.23 adds read-only `doxa model-facts` with per-field source dates and operator-selected review candidates. The `gpt-6-astra` supervisor and judge selectors have sourced facts and regression coverage; live account availability, latency, billed tier and provider charge remain unknown. Provider catalogs still control availability. |
| [Code graph](code-graph.md) | Rust and Python syntax queries and reviewed LORE snapshots recheck listed sources before complete claims. Git commands are bounded, while source opens/reads have a two-second caller deadline. A blocked worker can persist until process exit and later source reads fail closed. The [synthetic stream probe](codegraph-semantic-verification.md) remains disabled with `binding: unknown`. Atomic snapshots, analyzer/Engine trust, and an automatic index remain open. |
| [DOXA plugin API](plugin-api.md) | Owner-allowlisted text commands and status files are data only. The approved zero-grant CLI worker passed a seven-case delegated guest proof; a review-only receipt binds its exact test artifact. Read-only `doxa native-plugin host-check` inventories delegated cgroup membership and installed binary identities without issuing authority. A review-only installed-host proof adds a read-only check and nine-case acceptance run, but that live run has not occurred. The TUI has an owner-bound, cancellable run request; worker dispatch requires installed-host authority that production does not issue. Installed-host acceptance and production TUI admission remain closed; grants, hooks and provider extensions remain open. |
| [Mermaid transcript diagrams](mermaid.md) | Opt-in local previews, sandbox doctor and beta.16 Settings preflight exist. A private session PNG cache binds source, width, and renderer package identity. A pinned real CLI suite passed fixed diagrams in Linux sandbox; real terminal graphics QA and an optional installer decision remain open. |
| [Collection triage](collection-triage.md) | Suggested names, settled opt-in group sorting and verified local LORE pending rank exist. Beta.16 added verified project heading hues and hidden-tab urgency; beta.17 added pane-row navigation, manual collection hues and label rename. Beta.18 adds `/collection project-label` for freshly verified canonical roots; unresolved or mixed roots stay read-only. |
| [macOS daemon process coverage](https://github.com/docwilde/doxa/issues/197) | Portable crates and daemon process tests run in macOS CI; beta.15 verifies production peer delivery and fleet PID admission. An opt-in source-only Claude lifecycle harness is available; an authenticated macOS pass and protected Codex success remain unverified. |
