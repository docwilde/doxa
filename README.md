# DOXA

**Where belief earns knowledge.**

A terminal for working with a Claude agent whose memory you can trust — LORE-native, built on the Claude Agent SDK and Textual.

δόξα (dóxa): belief, opinion — as distinct from ἐπιστήμη (epistēmē), justified knowledge. Greek epistemology drew the line; DOXA implements it: everything the agent derives starts as doxa (cite-only, uncalibrated), and only what survives the dialectic — human approval or a calibrated outcome record — ascends to steer. LORE holds the engrams; DOXA is where they are examined.

Status: Phase 1 (post-validation-spike). See PHASE0_FINDINGS.md for the SDK groundwork.
